## 适用范围与联系方式

本政策适用于 Keyword Volume Lab 本地关键词搜索量工具。运营与联系邮箱为 zhaodong199208@gmail.com。如有隐私问题或数据删除请求，请联系该邮箱。

## 访问的数据及用途

工具使用 Google OAuth 登录，访问用户电子邮箱及邮箱验证状态，以确认授权账号；使用 Google Ads API 读取可访问的广告账号标识，并按用户提交的关键词、国家、语言和广告账号 ID 请求历史关键词指标。返回内容可能包含平均月搜索量、各月搜索量、广告竞争度与近似变体。

Google 的 adwords 授权范围包含广告账号管理能力，但本版本只实现读取广告账号与获取关键词历史指标，不实现广告投放、预算或广告系列修改。工具不读取 Gmail 邮件内容。

## 数据处理与存储

本地服务向 Google 发送完成 OAuth、读取账号和查询关键词所必需的请求。OAuth 客户端配置、访问令牌、刷新令牌与已验证邮箱保留在本地服务进程内存中；服务停止后不再保留。用户自行下载的 OAuth 客户端配置 JSON 属于用户管理的本地文件，应安全保管。

查询结果在本地浏览器中显示。用户可手动下载结果 JSON，下载文件由用户自行管理。本地查询工具未内置分析 SDK、广告追踪或远程结果数据库。本介绍及文档网站由 Vercel 托管，并使用 Google Analytics 统计网页访问情况；这些网站访问统计与本地工具的 Google Ads 授权令牌及查询结果分开，网站不接收本地工具的令牌或关键词结果。Google 作为接口提供方的处理活动适用其自身政策。

## 分享与使用限制

本工具仅为上述功能向 Google 发送必要数据，不将 Google 用户数据出售、分享给广告平台或用于模型训练。Keyword Volume Lab 对从 Google API 接收的信息的使用和转移遵守 [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy)，包括其中的 Limited Use 要求。如未来增加第三方服务或改变数据用途，应先更新实现与政策并取得适用授权。

## 断开与删除

点击“清除本次授权”会清除当前本地服务中的授权令牌与账号状态，但不会撤销 Google 账号侧已授予应用的权限。用户可在 [Google 账号的第三方连接管理页面](https://myaccount.google.com/connections)撤销应用权限。停止服务可清除进程内存中的客户端配置与令牌；已下载的配置与结果文件需由用户自行删除。

## 政策更新

若工具功能、部署方式或数据处理方式变化，应同步更新本政策，并在页面标注更新日期。公开部署前需重新核对令牌存储、访问控制与日志处理事实。
