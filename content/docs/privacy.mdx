title: 隐私
description: wikipie 通用隐私说明。
order: 3
---

wikipie 是个人站点与工具集合。除非某个工具页面明确说明，否则本站不要求注册账号，也不在服务端建立个人资料库。

## 工具密钥

SEO 工具和 AI 工具需要的 API key 保存在你的浏览器本地存储中。请求发出时，页面会把本次任务需要的 key 附在请求头里发送给本站接口，用于转发到对应服务商。

## 内容与日志

本站可能保留基础访问日志，用于排查错误、分析性能和维护服务稳定性。日志不用于建立用户画像。

## 第三方服务

部分工具会调用 Ahrefs、OpenAI、Anthropic、Google Gemini、DeepSeek 或其他你主动配置的服务商。对应请求会受这些服务商自己的隐私政策和服务条款约束。

## 联系

如果你希望删除某次测试内容或反馈隐私问题，可以通过站点公开的联系方式联系维护者。
