wikipie 提供个人内容、App 文档和若干 SEO / AI 辅助工具。使用本站代表你理解并接受以下说明。

## 工具输出

工具结果只用于辅助判断，不构成法律、财务、医疗或专业 SEO 承诺。你应自行复核 API 返回、AI 生成内容和最终发布结果。

## API key

你需要自行管理用于第三方服务的 API key，并确保这些 key 的使用符合对应服务商条款。不要在共享设备或不可信浏览器中保存敏感 key。

## 内容使用

本站原创文字、设计和代码示例可用于学习与参考。未经许可，不要批量复制、镜像或冒充本站内容。

## 服务变更

本站是个人项目，功能、文档、工具和可用性可能随时调整。维护者会尽量保持链接与文档准确，但不保证所有工具持续可用。
